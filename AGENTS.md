# Règles de collaboration

## Validation préalable obligatoire

- Ne jamais modifier le code sans validation explicite de l'utilisateur.
- Avant toute modification, expliquer clairement ce qui sera fait.
- Proposer un patch ou un plan de patch avant application.
- Attendre la validation de l'utilisateur avant d'appliquer le patch.

## Périmètre des changements

- Limiter les modifications au strict nécessaire.
- Ne pas reformater, déplacer ou refactoriser du code non concerné par la demande.
- Ne jamais annuler des changements existants sans instruction explicite.

## Communication

- Décrire les fichiers concernés avant intervention.
- Signaler les risques, hypothèses ou impacts potentiels.
- Après application validée, résumer les changements effectués et les vérifications réalisées.
